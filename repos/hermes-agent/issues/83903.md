# 83903 - Auto-title returns raw JSON fragments when max_tokens=64 truncates model response

- URL: https://github.com/NousResearch/hermes-agent/issues/83903
- Added: 2026-08-11

## Why claimable

P3 but high-value: 4 of last 10 sessions had garbage titles (`{"title"`,
raw JSON fragments) - visible user-facing degradation. Root cause named
precisely: agent/title_generator.py line 400 max_tokens=64 truncates the
two-stage title JSON mid-response; _extract_title_text (line 277) falls
through json.loads -> regex -> prose fallback which returns the raw
truncated fragment. Not provider-specific (any model ignoring
response_format or exceeding 64 tokens). Introduced in f726090d4
(2026-08-08) - recent regression.
