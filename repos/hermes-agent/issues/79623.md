# 79623 - Cron sessions omit workdir and Git repository provenance

- URL: https://github.com/NousResearch/hermes-agent/issues/79623
- Added: 2026-08-07

## Why claimable

`_launch_cwd_for_session` had `if source != "cli": return None`, so cron sessions recorded NULL cwd despite a configured workdir. Fix: cron branch reads `agent.runtime_cwd._session_cwd_override()` (the contextvar the scheduler pins), validates it's a dir, else None.
