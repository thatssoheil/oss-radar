# 79530 - search_files: content invisible in large non-hidden dirs + total_count under-reports

- URL: https://github.com/NousResearch/hermes-agent/issues/79530
- Added: 2026-08-07

## Why claimable

`rg | head -n fetch_limit` truncated rows, so content in large dirs was invisible and `total_count` was `len(fetched)`. Fix: when fetch hits the ceiling, run a dedicated untruncated count (`rg --count-matches`, `rg -l | wc -l`) and use it; fall back to estimate on count failure. Tested with a real 1300-file fixture - E2E verified 1300 (was 5).
