# 79471 - One-shot execution exits without closing the Relay session lifecycle

- URL: https://github.com/NousResearch/hermes-agent/issues/79471
- Added: 2026-08-07

## Why claimable

One-shot mode (`hermes -z` / `--oneshot`) hard-exits via `os._exit`, so the Relay conversation was never finalized: exported telemetry has session start + turn lifecycle but no session end. Clean, narrow, real user impact on telemetry integrity.
