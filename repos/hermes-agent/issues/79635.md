# 79635 - Desktop over Tailscale: hardcoded ws_ping_timeout drops sessions

- URL: https://github.com/NousResearch/hermes-agent/issues/79635

## Why claimable

Non-loopback hardcoded `ws_ping_interval=20.0/ws_ping_timeout=20.0` (Cloudflare Tunnel assumption) breaks Tailscale direct-mesh: 1006 drops, orphan reap, "session not found". Fix: read `dashboard.ws_ping_interval`/`ws_ping_timeout` from `load_config()`, default preserves today's behavior. Test: `_stub_uvicorn` fake Config captures kwargs.
