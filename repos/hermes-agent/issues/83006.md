# 83006 - [Bug] Ctrl+Z in CLI suspends the whole process group

- URL: https://github.com/NousResearch/hermes-agent/issues/83006
- Added: 2026-08-11

## Why claimable

P2 TUI bug. Ctrl+Z via `os.kill(0, SIGTSTP)` stopped the entire process
group, killing background jobs sharing the group (and a raw 0x1A paste byte
was destructive). Root cause cited with line numbers, single-line fix
surface (`cli.py` handle_ctrl_z), verifiable on main. No open PR at claim
time.
