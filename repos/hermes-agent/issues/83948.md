# 83948 - remote Ollama vision auto-routing uses persisted default provider after session model switch

- URL: https://github.com/NousResearch/hermes-agent/issues/83948
- Added: 2026-08-11

## Why claimable

P2, clear root cause. Session switched from persisted default (cloud-proxy)
to named remote Ollama custom provider (ollama-lan); image_input_mode: auto
fails to detect the Ollama model's vision capability, routes image through
text path. Root cause: _resolve_inference_base_url never considered the
requested provider identity AND shadowed it (local var requested_provider
reassigned to canonical provider inside runtime-lookup block).
