# 83736 - session claim without heartbeat can be reclaimed while original session keeps running

- URL: https://github.com/NousResearch/hermes-agent/issues/83736
- Added: 2026-08-11

## Why claimable

P3 with a real incident (5 files clobbered by two concurrent writers). A
session-side `kanban claim` has no heartbeat, so once the TTL expires the
dispatcher reclaims (can't terminate the session executor) and spawns a
worker into the same workspace - duplicate execution. Issue offered fix A
(disallow session claims, preferred) with an opt-in flag.
